# Cara berkontribusi

1. Temukan kesalahan atau kekurangan (kode, SKS, jenis, prasyarat, konsentrasi).
2. Buka **Issue** di repo ini, atau kirim **Pull Request** yang mengubah file di folder `semester/`.
3. Sertakan **sumber** (buku panduan, SK kurikulum, KRS) dan tahun kurikulumnya.
4. Jaga format tabel yang sama: Kode MK, Mata Kuliah, SKS, Jenis.

Data tanpa sumber yang jelas tidak akan digabung.
