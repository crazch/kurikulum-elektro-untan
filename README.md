# Kurikulum Teknik Elektro UNTAN

Daftar mata kuliah per semester Program Studi Teknik Elektro, Fakultas Teknik, Universitas Tanjungpura (UNTAN) Pontianak. Situs tidak resmi, dibuat oleh mahasiswa.

Versi situs web: https://crazch.github.io/kurikulum-elektro-untan/

**Sumber data:** Jadwal kuliah dan UAS Gasal 2021/2022 dan 2022/2023, serta jadwal kuliah Genap 2021/2022. Jenis: Wajib atau Pilihan sesuai tanda (P) di jadwal.

Semester 5 sampai 8 memuat mata kuliah dari beberapa konsentrasi dalam satu daftar, jadi tidak semua mata kuliah bertanda Wajib diambil oleh semua mahasiswa.
